# Mermaid Diagram Editor

A browser-based mermaid diagram editor with live preview, multi-tab support, and PNG/SVG export.

## Development

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build

```bash
npm run build
npm run preview
```

## Features

- Live preview with Monaco editor
- Multi-tab sessions
- LocalStorage persistence
- PNG and SVG export
- Light/Dark theme
- Sample templates
